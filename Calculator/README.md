# 🧮 Calculator using Kivy

A simple GUI-based calculator developed using the **Kivy Framework** in Python. This project demonstrates the fundamentals of event-driven programming and graphical user interface (GUI) development.

> **Note:** This project was created for learning purposes. It may not run on Python 3.14 because Kivy has not yet released full compatibility for this Python version.

---

## 📌 Features

- Interactive graphical interface
- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Decimal number support
- Clear (C) button
- Real-time expression display
- Result evaluation using Python expressions

## ▶ How It Works

1. The user clicks the calculator buttons.
2. Every button press updates the display.
3. The "=" button evaluates the mathematical expression.
4. The result is displayed instantly.
5. Invalid expressions are handled gracefully.
